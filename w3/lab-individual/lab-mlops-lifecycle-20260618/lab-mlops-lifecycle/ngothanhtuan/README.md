# MLOps Anomaly Detection Pipeline - ngothanhtuan

Hướng dẫn chạy pipeline phát hiện bất thường từ đầu đến cuối: Đầu tiên, khởi động Docker Compose stack bằng cách chạy `bash scripts/start_stack.sh` để kích hoạt MLflow, PostgreSQL, Prometheus, Pushgateway và Grafana, sau đó chuẩn bị dữ liệu bằng `uv run python data/generate_data.py`. Tiếp theo, huấn luyện mô hình v1 trên dữ liệu chuẩn bằng cách thiết lập biến môi trường và chạy `export MLFLOW_TRACKING_URI=http://localhost:5000` và `uv run python ngothanhtuan/pipeline.py --data data/baseline.csv`. Khởi chạy server FastAPI phục vụ mô hình bằng lệnh `uv run python ngothanhtuan/serve.py` ở một terminal riêng biệt. Cuối cùng, thực hiện quy trình phát hiện drift dữ liệu, huấn luyện lại mô hình v2 trên cửa sổ trượt (sliding window), chạy kiểm tra tập holdout, thăng cấp mô hình và kích hoạt giám sát sau triển khai với tính năng tự động khôi phục (auto-rollback) bằng lệnh: `uv run python ngothanhtuan/retrain.py --reference data/baseline.csv --current data/drifted.csv --holdout data/holdout.csv --post-deploy-eval data/post_deploy_eval.csv --auto-approve`.
